# 関係・分類の説明モデル

## 目的と単位

対象が何に属し、何とどう関係するかを説明するモデルです。一件は、特定の文脈・時点で、対象間の関係または分類を説明するまとまりです。組織の所属、下位組織、関連団体、概念の分類などに使えます。あらゆる因果関係を説明するためのモデルではありません。

## 構成要素と関係

| 概念 | 定義 |
| --- | --- |
| 対象 | 説明する個体または種類。実在する組織と「学会」という種類などを区別する。 |
| 関係・分類 | 対象間の結び付き、または分類基準に照らした位置づけ。誰から誰への関係かを示す。 |
| 関係の種類 | 所属、部分、関連、歴史的なつながり、機能的類似など、今回区別する結び付きの意味。 |
| 文脈・時点・基準 | 関係が成立する制度、定義、期間、分類基準。現在の所属と過去の所属は別の主張になる。 |
| 根拠と確定性 | 関係を示す資料や観察、解釈の根拠、確認できない部分。 |

所属関係は、協力関係や名称の類似からは導けません。ある種類の下位分類と、ある組織の下部組織も区別します。同じ対象間に、協力関係と歴史的なつながりが同時に成立することはあります。関係の種類が異なるだけで矛盾とはみなしません。

## 記述方法

問われた関係について先に回答し、混同されやすい関係を必要に応じて対照します。前提が誤っている場合は、何をどう修正したかを示してから、読者の理解に役立つ位置づけを説明します。問いを黙って別の関係へ置き換えません。

資料が同じ対象・時点・種類の関係について食い違う場合は、競合として示します。資料に見当たらないことと、関係が存在しないと確認されたことを区別します。図を使う場合は、線の向きと意味を読み取れるようにします。

## 適用例と境界

架空の規約に「研究会Bは協会Aの内部組織」、広報資料に「団体Cと協会Aが共同開催」とある場合、Bは内部組織、Cは共同開催の相手と説明できます。共同開催だけからCも下部組織と結論づけることはできません。Cの所属が別途不明でも、共同開催の事実は説明できます。

名称変更後も同じ団体なのか、統合による新団体なのかが分からない場合は、対象の同一性を未確定として残します。こうした情報不足と、所属・協力を区別できないモデル上の不足は別です。

## 定義を確かめる問い

- 対象の種類と個体、所属と協力、現在と過去を区別して説明できるか。
- 関係の不在、未確認、同じ条件下での資料の競合を分けられるか。
- 前提を修正しても、元の問いに何を回答したか追跡できるか。
