# Generic EtD モデル

## 1. 目的と対象

Generic EtD は、GRADE Evidence-to-Decision（EtD）を参考に、日常生活やさまざまな分野で使えるように整理した、レポート形式の概念モデルです。目的に照らして複数の立場や行為を評価し、根拠、価値判断、条件を示しながら、何を推奨するかを明らかにします。本モデルの定義と報告方針は、この用途のために定めるものであり、GRADE の公式なモデルとして扱いません。

対象には、購入、参加、学習方法、技術選定、組織の方針などの選択を含めます。理解や説明も「ある立場をとる」という意思決定・行為として扱います。例えば、出来事をどの観点から理解するか、概念をどのように捉えて説明するかも、評価と推奨の対象になります。

基本原則は、**比較は多面的に、推奨は立場を明確に**です。候補ごとの利点や不利益を整理したうえで、原則として推奨する立場・行為を決めます。推奨の強さは、根拠と不確実性、価値の違い、実行条件を踏まえて判断します。

## 2. レポートの単位と構成要素

一つのレポートは、一つの主題に関する中心的な判断と、その関連論点を扱います。中心となる推奨を示し、それを支える判断や、付随する論点・推奨も必要に応じて収めます。関連論点を追加する場合は、それが中心的な判断の根拠、条件、影響のどれを説明するかを明らかにします。

レポートを構成する概念を、次のように定義します。この表は記述内容の定義であり、回答ごとに同じ見出しや表を再現するための書式ではありません。

| 構成要素 | 定義と記述内容 |
| --- | --- |
| 主題と目的 | 何について、何を判断・説明するレポートか。問題の重要性や、検討する必要がある理由もここに記述する。 |
| 状況と前提 | 判断の対象者、利用場面、時点、制約、既知の事実、依頼の解釈。確認できた内容と仮説を区別する。 |
| 選択肢 | 評価する立場・行為。各候補が何を含み、何と比較されるのかを説明する。 |
| 評価項目 | 選択肢の違いを捉える観点。目的と状況に応じて採用し、各候補を共通の観点から比較する。 |
| 根拠と不確実性 | 個々の記述・評価・推奨を支える資料や推論と、その限界。結論に影響する不足情報も含む。 |
| 総合判断と推奨 | 評価項目間の関係と優先順位を踏まえた結論。何を推奨し、なぜ他の候補より支持するかを示す。 |
| 関連論点 | 中心となる判断を支える補助的な判断や、付随する影響・推奨。中心的な判断との関係を示す。 |

評価は、選択肢、評価項目、状況を結び付けた判断です。例えば、同じ学習方法でも、目的、既有知識、使える時間が変われば評価は変わります。ある状況での評価を、その条件を外した一般的な優劣として報告しません。

## 3. 選択肢と比較

選択肢は、目的に対して採りうる立場・行為を、違いが分かるまとまりとして記述します。候補の内容と範囲をそろえ、表面的な言い換え、意図的に弱くした案、抽象度の異なる案を比較対象にしないよう点検します。現状維持や中間案も、その状況で採る理由がある場合に含めます。

理解や説明を扱う場合は、何を理解・説明するための立場なのかを明示します。例えば、用語の違いを説明するなら、辞書的な定義を中心にする立場と、実際の使い分けを中心にする立場を、読者の目的に照らして比較できます。説明の観点を選ぶことと、資料で確認できる事実の正誤を判断することは区別します。

比較を行う場合は、少なくとも二つの候補の内容が分かるようにします。候補が不足している段階では、その不足を記述し、比較のためだけに対案を作りません。レポートは、評価していない候補まで含めた最適性を主張しません。

## 4. 評価項目

次の項目を共通の初期候補とします。すべてのレポートで全項目を評価する必要はありません。目的と状況に照らして採用し、結論や読者の理解に影響する違いを記述します。影響がありそうな項目を評価できない場合は、情報不足なのか、今回の対象範囲から外すのかを示します。

### 4.1 望ましい効果と望ましくない効果

各選択肢によって、誰に、どのような変化が生じるかを評価します。望ましい効果と望ましくない効果をそれぞれ記述し、他の候補と比べた違いを中心に報告します。対象者、期間、発生条件、大きさが判断に関わる場合は、その範囲を示します。

理解や説明に関する効果には、目的に沿った理解を得られること、誤解が減ること、必要な区別が失われることなどを含められます。読みやすさや分かりやすさを、説明内容の正確さと同一視しません。

### 4.2 必要な資源

実現や利用に必要な金銭、時間、人員、設備、情報などを記述します。量や条件が分かる場合は具体的に示し、不明な場合は、何が分かれば比較できるかを示します。「低コスト」と評価するだけでなく、誰が何をどの程度提供する必要があるかを説明します。

### 4.3 負担

当事者が経験する、または予想される身体的・心理的・認知的な負担や、生活・業務上の煩雑さを記述します。必要な資源の量と、当事者にとっての負担は分けて扱います。同じ所要時間でも、作業への慣れや生活上の制約によって負担は異なりえます。

本人が述べた負担、他者の報告から推定した負担、まだ確認していない負担を区別します。本人が負担ではないと述べた内容を、記述を短くする過程で「負担は不明」に置き換えません。

### 4.4 実行可能性

選択肢が、対象者の能力、利用できる環境、制度、技術、時間などの条件のもとで実現できるかを評価します。成立に必要な前提と、妨げになる条件を示します。資源が少なく済むことだけを理由に、実行可能と判断しません。

対象者の背景について合理的な推測を用いる場合は、その手掛かりと仮説であることを示します。選択肢を実行可能にするための助言も含められますが、確認済みの条件と追加で必要な条件を分けます。

### 4.5 価値と優先順位

何を望ましい結果とみなし、どの違いを重視するかを記述します。本人の発言、関係者間の価値の違い、報告者が判断のために置いた前提を区別します。価値の違いによって推奨が変わる場合は、どの優先順位が結論を支えているかを示します。

受け入れやすさを扱う場合は、その理由に応じて、価値と優先順位、負担、実行可能性などに記述します。独立した基本項目として一律には設けません。

### 4.6 影響の分布と公平性

利益、不利益、資源の提供、負担が、誰にどのように配分されるかを記述します。本人だけでなく、影響を受ける関係者や集団も対象に含めます。集計した利益が同じでも、一部の人へ不利益が集中する場合は、その違いを示します。

影響の分布について確認できる事実と、その分布を公平または不公平と評価する判断を区別します。公平性を評価する場合は、負担の均等、必要性への配慮、機会の確保など、採用した観点を説明します。推奨を変えない場合でも、他者への影響を読者が把握するために必要な情報は報告します。

## 5. 根拠と不確実性

根拠と不確実性は、個々の記述・評価・推奨に対応させます。観察や資料に記された内容、そこからの推論、価値判断を区別し、どの情報がどの判断を支えるかを示します。引用を付ける場合は、資料が支える範囲を超えて結論を広げません。

情報が未確認なのか、不明なのか、該当しないのか、否定されているのか、情報同士が競合しているのかを、判断に必要な範囲で区別します。ある効果の根拠が見つからないことを、その効果がないという根拠として扱いません。

推奨に影響する不確実性は、個別の評価に加えて総合判断でも説明します。何が不明か、その不明点がどの評価を変えうるか、現時点の推奨をどの程度制限するかを示します。確信の程度に数値や区分を用いる場合は、その根拠を示し、見かけの精密さを作りません。

## 6. 総合判断と推奨

総合判断では、評価項目を列挙するだけでなく、どの違いを優先し、どの不利益を受け入れて結論に至るかを説明します。同じ事象を効果、資源、負担などの複数の側面から記述した場合は、それらの関係を示し、独立した利点や不利益として重複計上しないようにします。

原則として、レポートが推奨する立場・行為を明示することを強く推奨します。「AにもBにも良さがある」という説明だけで終えず、現在の目的と条件のもとで、どちらを支持するか、その理由を示します。これは、一つの候補を例外なく強く推奨するという意味ではありません。推奨する対象を決めることと、推奨の強さを判断することは分けて扱います。

推奨には、支持する候補、他の候補より支持する理由、成立条件、支持の程度を含めます。結論を左右する価値や不確実性がある場合は、それも示します。根拠が限定されていても暫定的な立場を示せる場合は、限定の理由を添えます。支持する候補を決める根拠が不足する場合は、その不足と、決めるために必要な情報を明示します。

条件によって推奨が分かれる場合も、どの条件で何を選ぶかを明確にします。複数の候補を組み合わせる場合は、各候補の役割と組み合わせる理由を説明します。単に併記することで、対立する目的や不利益の検討を省略しません。

## 7. 報告の方法と詳しさ

報告は、依頼された答えや成果物に沿って構成します。中心となる推奨や回答を読者が把握できる位置に置き、比較の根拠、優先した違い、成立条件へと説明をつなげます。詳しい比較を求められた場合は、各候補を共通の評価項目で見渡せる表や文章を用います。

記述量は、判断の影響、根拠の不確実性、関係者への影響、読者が求める詳しさに合わせます。短い回答では、推奨、決め手、結論を左右する条件に絞れます。明示された文字数、回答のみ、コマンドのみなどの制約を尊重し、モデルの項目をすべて見せるために成果物を膨らませません。

背景、具体例、経験、学習支援なども、評価や推奨の理解・利用を助ける場合に含められます。本モデルはそれらの説明モデルとの固定の対応や必須の併用を定めません。

## 8. 適用と拡張の範囲

本モデルの基本範囲は、目的と状況の整理、選択肢の評価・比較、総合判断と推奨、その報告です。実行可能性を説明するための条件や助言は含めますが、実施計画の策定、実施後の監視、継続的な再評価は基本範囲に含めません。

分野や事例に固有の項目が必要な場合は、何を判断するために加えるかを説明します。既存項目の意味を変更する場合は、その変更と理由を明示します。参照モデルから得た観点は、事例について確認した事実や、本人の価値の代わりにはなりません。

この文書は、レポートに何を記述し、どう評価・報告するかを定義します。特定の保存形式、固定の採点法、調査や聞き取りの実行手順は定めません。
