# 学習を支える説明モデル

## 目的と単位

読者の既有知識と新しい内容をつなぎ、理解、練習、応用を支える説明のモデルです。一件は、ある学習者像と到達目的に対する一まとまりの学習支援です。一つの概念の説明や短い練習にも使え、全課程の設計を前提にしません。

## 構成要素と関係

| 概念 | 定義 |
| --- | --- |
| 学習者の前提 | 既有知識、経験、利用環境、時間など。本人が示した内容と推定した内容を区別する。 |
| 到達目的と学習対象 | 何を理解・識別・実行できるようになるかと、そのために扱う内容。 |
| 橋渡し | 既知の内容との対応、対比、類推、および対応が成り立たない箇所。 |
| 例と説明の順序 | 内容を具体化する例と、理解に必要な依存関係に沿った説明の並び。 |
| 練習と確認 | 学習者が試す課題と、回答・実行結果をどう確かめるか。 |
| 応用と到達状況 | 別の場面への適用と、実際に確認できた理解や実行の範囲。 |

橋渡しは既有知識と学習対象の関係を示します。類似する部分だけを示すと誤学習を招く場合は、相違点を併記します。練習は到達目的に対応し、確認方法は何を確かめたかを明らかにします。説明を提示したこと、練習を完了したこと、別の場面で使えたことは異なる状態です。

## 記述方法

読者が知っていることから、新たに必要な区別へつなげます。目的や前提が未明示でも仮説を置いて説明できますが、学習者の能力を確定したものとして扱いません。理解に必要な最小の例から、目的に応じて練習や応用へ広げます。

練習を掲載する場合は、解答例、期待される結果、点検の観点などの確認方法を添えます。課題を示すだけでフィードバックを行ったとはみなしません。学習者の回答がない場合、習得状況は未確認です。

技術的な説明の根拠と、学習方法が有効だという根拠は区別します。作成者が説明上有用と判断した類推や順序を、検証済みの教育効果として報告しません。練習や応用課題は任意であり、求められた短い説明に課程全体を追加する必要はありません。

## 適用例と境界

架空の利用者が表計算のフィルタを知り、データ検索の条件指定を学びたいとします。「条件に合う行を選ぶ」という対応から説明し、新しい操作に固有の条件の書き方を例示できます。類似する操作でも、結果の保存方法まで同じとは仮定しません。

例を読んだだけなら理解は未確認です。練習で一つの条件を正しく書けても、別の条件へ応用できることまでは確認していません。即時の操作結果だけが必要な依頼に、学習の一連の段階を強制しません。

## 定義を確かめる問い

- 既有知識との対応と、その対応が破綻する箇所を説明できるか。
- 練習と確認方法を到達目的に結び付けられるか。
- 説明済み、実行確認済み、応用確認済み、未確認を区別できるか。
