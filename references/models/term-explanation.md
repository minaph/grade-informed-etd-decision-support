# 用語・概念の説明モデル

## 目的と単位

語や概念をどう理解し、場面に応じてどう使い分けるかを説明するモデルです。一件は、特定の言語・分野・使用場面で、一つ以上の語の意味や関係を説明するまとまりです。語の対比は可能ですが、一語の説明にも使えます。

## 構成要素と関係

| 概念 | 定義 |
| --- | --- |
| 語・表現 | 説明対象の表記や言い回し。意味そのものとは区別する。 |
| 意味・概念 | その文脈で表す内容と、理解に必要な区別。 |
| 用法と条件 | どの場面・分野・構文で使われ、文体や語調、受け取られ方がどう異なるか。 |
| 対比・対応 | 語同士の違い、同じ語の複数の意味、同じ概念を表す複数の表現の関係。 |
| 具体例 | 区別や用法を具体化する例。採取された実例と説明用の作例を区別する。 |
| 根拠と範囲 | 辞書、用例、資料、話者の判断など、説明の出所と適用できる範囲。 |

語と意味は一対一とは限りません。同じ表記が分野によって別の意味を持ち、同じ概念に複数の表現が対応する場合があります。定義上の違いと、実際の使用傾向も区別します。使用頻度の差と、使用できるかどうかの規則は同じではありません。

## 記述方法

理解や使い分けに必要な区別を先に示し、その区別が分かる例や使用条件を添えます。歴史や語源は現在の違いを説明する場合に含め、現在の意味を歴史だけから決めません。

用法についての資料が限定的な場合は、その範囲を示します。作例は意味の違いを示せますが、頻度や一般的な受け取られ方の証拠にはなりません。話者・作成者の判断を用いる場合も、資料に裏付けられた主張と区別します。資料の定義が異なる場合は、分野や使用条件の差なのか、同じ範囲での競合なのかを説明します。

短い回答では中心的な区別と必要な限定に絞れます。例や練習、歴史を必ず付ける必要はありません。

## 適用例と境界

架空の業務用語集で「受付」を申込みの受領、「承認」を審査後の許可と定義しているとします。「受付済み」は「承認済み」を含意しないと説明できます。別の資料で「受付」が窓口の場所を指すなら、同じ語の別の意味として扱います。この区別は、その業務用語集の外でも常に成立するとは限りません。

辞書に載っていないことだけで、ある用法が存在しないと結論づけません。どちらの表現を使うべきかの判断が必要な場合は、相手と使用目的に照らした条件を示します。

## 定義を確かめる問い

- 語の多義性と、同じ概念の複数表現を区別できるか。
- 定義上の意味、使用条件、説明用の作例、用法の証拠を分けられるか。
- 歴史的な説明を現在の用法の根拠と混同せず、一文でも重要な区別を示せるか。
