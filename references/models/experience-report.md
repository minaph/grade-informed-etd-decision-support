# 出来事・経験のレポートモデル

## 目的と単位

出来事や活動がどのような条件で行われ、当事者にどう経験されたかを伝えるモデルです。主な経験の単位は、ある主体が、特定の出来事・活動を、ある時点・条件・役割で経験した内容です。一つのレポートには、共通の出来事に関する複数人・複数回の経験や、これから参加する場合の見通しを収められます。

## 構成要素と関係

| 概念 | 定義 |
| --- | --- |
| 出来事・活動 | 開催された催しや行われた活動。同名の毎年の催しでも、開催回は区別する。 |
| 主体と役割 | 誰が参加・観察し、来場者、出店者、運営者などのどの立場にいたか。 |
| 条件 | 時点、場所、アクセス、参加条件、混雑、環境など、活動や経験を左右する事情。 |
| 経験の報告 | 主体が見聞きしたこと、行ったこと、感じたこと。観察内容と感想を区別する。 |
| 見通しと含意 | 過去の報告や現在の条件から予想する経験と、準備・参加方法などへの含意。 |
| 情報源と限界 | 本人の報告、第三者による記録、画像、規定などの出所と、分かる範囲。 |

出来事の開催条件と、一人の経験は異なる対象です。同じ回でも役割、時間帯、活動内容によって経験は異なります。相反する感想だけで、どちらかが誤りとは判断できません。過去の経験は今回の見通しの手掛かりになりますが、同じ結果を保証しません。

## 記述方法

何の活動を、どの立場から理解するための報告かが分かるようにします。読者の目的が未確定なら、来場と出店などの解釈を条件付きで扱えます。主体の意図を推定した場合は、確認された意図と区別します。

経験を伝える際は、その意味を変える時点・条件を伴わせます。画像は写っている場面を具体化できますが、一枚だけで開催期間全体の混雑や満足度を代表するとはいえません。観察、感想、複数報告のまとめ、将来への予想を読み分けられるようにします。

経験談がない場合も、確認された参加条件や活動内容は説明できます。経験が不明であることを、楽しさや負担がないことに置き換えません。準備への助言は、どの条件や予想に対応するかを示します。

## 適用例と境界

架空例として、前年の来場者が「正午は混んでいた」、出店者が「搬入に時間がかかった」と報告し、今年は会場が変更されたとします。二つの報告は、役割の異なる過去の経験として併記できます。今年の混雑や搬入時間は未確定であり、会場変更を踏まえて見通しを限定します。

架空の説明例を実際の参加者の証言として報告してはなりません。このモデルだけで代表性や因果効果を証明することもできません。

## 定義を確かめる問い

- 出来事の条件と個々の経験、異なる役割や開催回を区別できるか。
- 観察・感想・現在の条件・将来の予想を混同せず伝えられるか。
- 経験資料がなくても、分かる条件と不明な経験を分けて報告できるか。
