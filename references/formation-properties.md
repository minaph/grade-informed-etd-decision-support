# Decision Formation Property Model

The property contract now lives in the reusable
[decision-structuring subskill](../skills/decision-structuring/SKILL.md).
Read its [property model](../skills/decision-structuring/references/formation-properties.md)
for Context, Questions, Alternatives, and the generated Mermaid Tree.

This parent skill invokes it for every request as an internal diagnostic.
Keep the sketch minimal and invisible for direct, answer-only, command-only,
or fixed-format requests. Show the Tree for moderately complex, deep,
research-dependent, or explicitly structural requests.

The parent owns invocation and visibility. For research, interviews,
and appraisal integration, use [the parent workflow](question-formation.md).
